# Security policy

## Supported versions

Security fixes are provided for the latest stable 1.x release. Development snapshots are not supported releases.

## Reporting a vulnerability

Do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting for `windorion/sentry` when it is enabled, or contact the repository owner privately. Include the affected version, operating system, reproduction steps, and expected impact. Please allow time for triage and a coordinated fix before disclosure.

Windorion Sentry does not require elevated privileges. Treat configuration files, monitored logs, and exported reports as sensitive data, and install binaries only from the repository's official GitHub Release assets after checking the published SHA-256 checksum.
